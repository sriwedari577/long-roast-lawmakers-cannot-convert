A single satirical sentence roasting the lawmakers who write the rules for artificial intelligence, crypto and the internet, yet cannot convert a file to PDF: their chairman emails staff a crooked phone photo of his printed bill and asks someone to turn it into a PDF.

## What it does

Writes exactly one sentence to `entry.txt` in the output directory. The sentence sets up the lawmakers' authority first, then undercuts it with the specific file they cannot convert, landing the punch on the final words.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/longroast-out node main.ts
```

This writes `/tmp/longroast-out/entry.txt` containing the single roast sentence.
